# 🔐 Solana Web3 Wallet

A non-custodial Solana wallet built with React + TypeScript — create, import, send, and receive SOL directly in the browser. Your private key never leaves your device.

## ✨ Features

- 🆕 Create a new Solana wallet with a generated seed phrase
- 📥 Import an existing wallet via seed phrase
- 💸 Send SOL to any address
- 📤 Receive SOL with your public address
- 🔒 Password-protected profile with AES-GCM encryption
- 🛡️ Private key encrypted and stored locally — never sent to a server

## 🛠️ Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS
- `@solana/web3.js`
- `react-router-dom`
- Web Crypto API (AES-GCM encryption)
